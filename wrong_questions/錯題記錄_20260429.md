## 第1題｜單元：監督式學習 vs 非監督式學習

**題目**：關於監督式學習與非監督式學習的目標，下列敘述何者錯誤？

**你的答案**：3、5、6  
**正確答案**：2、3、5

**解析**：正確答案為 D。選項 2 說「監督式學習的典型應用為分類與迴歸，通常不適合應用於異常偵測任務」→ 這是錯誤的，因為監督式學習其實也可以應用於異常偵測（如 One-Class SVM、Autoencoder 重構誤差）；選項 3 說「非監督式學習若搭配少量標註資料，即會完全轉化為監督式學習」→ 這是錯誤的，半監督式學習仍保留非監督成分；選項 5 說「所有監督式學習任務都必須要有大量完整標註資料，否則無法進行任何有效的模型訓練」→ 這是錯誤的，遷移學習、少量樣本學習等方法可以在標註資料有限時進行訓練。

**錯誤類型**：❌ 對監督式學習應用範圍認知不足；❌ 混淆了半監督式學習與監督式學習的邊界；❌ 不了解少量標註資料的替代方案

**正確觀念**：  
- 監督式學習不只分類/迴歸，也可做異常偵測（如使用標註過的異常樣本）  
- 非監督 + 少量標註 = 半監督式學習，不會「完全轉化」為監督式  
- 小樣本學習、遷移學習、Active Learning 都可以緩解標註資料不足的問題

## 第2題｜單元：大型語言模型與批次推論（Batch Inference）

**題目**：某雲端服務公司將大型語言模型部署於線上系統，以批次推論處理每日上百萬筆請求。下列哪一項通常不會被視為批次推論階段的主要難題？

**你的答案**：4. 在叢集環境中精確安排推論任務，以提升 GPU/TPU 等硬體資源的利用率  
**正確答案**：1. 如何確保訓練語料的涵蓋性與標註品質，以避免模型偏差影響輸出

**解析**：正確答案為 A。選項 1 提到的是「訓練階段」才會處理的問題（語料涵蓋性與標註品質），而非「批次推論階段」的挑戰。批次推論的難題主要是：任務排程、延遲瓶頸、成本優化、輸出格式處理等。

**錯誤類型**：❌ 混淆了「模型訓練」與「模型推論（Inference）」的階段和挑戰

**正確觀念**：  
- AI 專案流程分為：訓練（Training）→ 驗證（Validation）→ 推論（Inference）  
- 推論階段的挑戰：延遲、吞吐量、成本優化、硬體利用率、輸出後處理  
- 訓練階段的挑戰：資料品質、模型偏差、過擬合、梯度消失等

## 第3題｜單元：可解釋人工智慧（XAI）— LIME

**題目**：LIME（Local Interpretable Model-agnostic Explanations）最核心的應用目的是什麼？

**你的答案**：3. 將黑箱模型轉換成完全可解釋的模型作為替代  
**正確答案**：1. 解釋單一樣本（局部預測）的黑箱模型決策過程

**解析**：正確答案為 A。LIME 的核心精神是「局部解釋」→ 對某一個特定輸入樣本，解釋黑箱模型為什麼做出那個預測。LIME 並不會把黑箱模型換掉，而是在模型外層建立一個局部可解釋的代理模型（surrogate model）來解釋該筆預測。

**錯誤類型**：❌ 誤解 LIME 的目的（局部解釋 vs 整體替換）

**正確觀念**：  
- LIME = Local Interpretable Model-agnostic Explanations  
- 核心理念：對「單一預測結果」進行局部解釋，而非取代整個黑箱模型  
- 其他 XAI 方法：SHAP（看全局特徵重要性）、Grad-CAM（視覺化 CNN 決策）、Attention Visualization（Transformer）

## 第4題｜單元：資料前處理 — 異常值（Outlier）處理

**題目**：醫院研究團隊收集病患收縮壓數據，大致呈常態分布。下列哪一種做法最合適處理極端血壓數值？

**你的答案**：4. 將檢測到的離群值以 Label Encoding 編碼，轉換為序號標籤以避免影響原始分布  
**正確答案**：3. 透過 Z分數（Z-score）或標準差範圍檢測異常值，並依研究需求決定是否調整或移除

**解析**：正確答案為 C。Label Encoding 是用於類別型資料（將類別轉為數字），不應用於連續型數值資料的異常值處理。正確做法是先用 Z 分數或 IQR 方法檢測異常值，再根據研究需求決定處理方式（移除、保留、或以均值替代）。

**錯誤類型**：❌ 混淆了特徵編碼方法（Label Encoding）與異常值處理的用途

**正確觀念**：  
- 異常值檢測方法：Z-score（常態分布）、IQR（四分位距）、DBSCAN、Isolation Forest  
- Label Encoding：用於「類別型」特徵（如性別、血型），不是用來處理數值異常值  
- 異常值處理選項：移除（Winsorizing/Trimming）、保留、或以中位數/均值替代

## 第5題｜單元：特徵工程 — 編碼方法（Encoding）

**題目**：旅遊平台預測顧客是否會再次訂房，「主要交通方式」（火車/飛機/自駕/公車）應採用什麼編碼？

**你的答案**：2. 序數編碼（Ordinal Encoding）  
**正確答案**：4. One-hot 編碼（One-hot Encoding）

**解析**：正確答案為 D。Ordinal Encoding 適用於有「順序關係」的類別（如學歷：國小/國中/大學/碩士），但交通方式（火車/飛機/自駕/公車）之間沒有順序關係，應該用 One-hot Encoding 將每個類別展開為獨立的二元特徵。

**錯誤類型**：❌ 不清楚 Ordinal Encoding 與 One-hot Encoding 的適用場景

**正確觀念**：  
| 編碼方法 | 適用場景 | 範例 |
|---------|---------|------|
| Label Encoding | 類別轉數字（無順序關係但需數值輸入） | 城市名稱 |
| Ordinal Encoding | 有順序關係的類別 | 學歷、職級 |
| One-hot Encoding | 無順序關係的類別（類別數量不多） | 交通方式、性別 |
| Target Encoding | 高基數類別（類別數量很多） | 用戶ID、商品類別 |

## 第6題｜單元：特徵工程 — 數值標準化（Normalization/Standardization）

**題目**：員工離職預測模型，各特徵數值範圍差異大（績效 1-5、加班 0-80、年齡 20-65）。下列哪一種方法最適合？

**你的答案**：3. One-hot 編碼（One-hot Encoding）  
**正確答案**：4. 數值標準化（Numerical Standardization）

**解析**：正確答案為 D。One-hot Encoding 是用於類別型特徵，數值型特徵範圍差異大應該用 Standardization（Z-score）或 Min-Max Scaling。梯度下降類模型（如邏輯迴歸）對特徵尺度敏感，標準化可以加速收斂並避免權重偏斜。

**錯誤類型**：❌ 混淆編碼方法（類別 vs 數值）與標準化方法

**正確觀念**：  
- 數值標準化（Standardization/Z-score）：將特徵轉換為均值 0、標準差 1 的分布，適用於梯度下降類模型  
- Min-Max Scaling：將特徵縮放到 [0, 1] 區間，適用於對尺度不敏感的模型（如樹類模型）  
- 樹類模型（Random Forest、XGBoost）對特徵尺度不敏感，通常不需要標準化

## 第7題｜單元：正則化（Regularization）— L1 vs L2

**題目**：關於 L1、L2 正則化，下列敘述何者正確？

**你的答案**：4. L2較L1正則化方法會將特徵權重趨近於零  
**正確答案**：3. L1運用減少權重的絕對值來控制模型的複雜度

**解析**：正確答案為 C。選項 4 是錯的，L2 正則化是將權重「縮小」但不會趨近於零（除非權重本來就很小），L1 正則化才會將不重要的特徵權重直接推到精確的零（產生稀疏解）。

**錯誤類型**：❌ 混淆 L1 與 L2 對權重的影響

**正確觀念**：  
| 特性 | L1（ Lasso） | L2（Ridge） |
|------|------------|------------|
| 懲罰項 | \|w\|（絕對值） | w²（平方） |
| 權重變化 | 線性遞減，可能到 0 | 指數遞減，趨近但不為 0 |
| 解的特性 | 稀疏解（特徵選擇） | 平滑解（抗過擬合） |
| 適用場景 | 特徵選擇、高維資料 | 共線性特徵、所有特徵都重要 |

## 第8題｜單元：Lasso 模型與 L1 正則化

**題目**：Lasso 模型中，L1 正則化導致參數收斂為零的原因是什麼？

**你的答案**：1. L1正則化忽略目標變數  
**正確答案**：3. L1對大係數懲罰較強，促使稀疏解

**解析**：正確答案為 C。L1 正則化的懲罰項是絕對值，在最佳化過程中會讓不重要的特徵權重逐步線性遞減到精確的零（因為絕對值函數的尖銳角落在零點不可微，導致權重容易停在零）。

**錯誤類型**：❌ 對 L1 正則化機制的理解錯誤

**正確觀念**：  
- L1 正則化 = λ∑\|w\|，透過懲罰大權重來防止過擬合，同時會將不重要特徵推到零  
- L2 正則化 = λ∑w²，懲罰大的平方項，讓所有權重一起縮小但不為零  
- Elastic Net = L1 + L2，結合兩者優點

## 第11題｜單元：AI 模型選擇 — 監督式學習演算法

**題目**：金融科技公司開發違約風險預測系統，特徵數量多且希望提升穩定性與泛化能力。最適合的模型？

**你的答案**：1. 邏輯迴歸（Logistic Regression）  
**正確答案**：4. 隨機森林（Random Forest）

**解析**：正確答案為 D。邏輯迴歸是線性模型，對於特徵數量多且關係複雜的資料，拟合能力有限。隨機森林是集成方法，透過 Bootstrap Aggregating 提升穩定性，且能自動處理特徵互動和非線性關係，更適合高維資料和需要高泛化能力的場景。

**錯誤類型**：❌ 不了解不同模型的能力邊界

**正確觀念**：  
| 模型 | 優點 | 缺點 | 適用場景 |
|------|------|------|---------|
| 邏輯迴歸 | 可解釋、速度快 | 線性假設、無法處理複雜關係 | 基線模型、線性可分的資料 |
| 決策樹 | 可解釋、直覺 | 容易過擬合 | 小資料、需可解釋性 |
| 隨機森林 | 抗過擬合、穩定 | 可解釋性較低 | 高維資料、複雜關係 |
| XGBoost/LightGBM | 最高準確率 | 需調參、黑箱 | Kaggle 競賽、工業應用 |
| 深度學習 | 自動特徵學習 | 需要大量資料、計算資源 | 影像、NLP、複雜模式 |
